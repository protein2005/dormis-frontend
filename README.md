# Frontend — Інформаційна система автоматизації гуртожитків

Цей репозиторій містить **фронтенд-частину** дипломного проєкту **«Інформаційна система автоматизації адміністративно-побутової діяльності гуртожитків»**.

Frontend реалізований як адаптивний вебзастосунок для мешканців гуртожитку, комендантів та адміністрації.

---

## 🧩 Призначення проєкту

Мета фронтенду — забезпечити зручний, швидкий та зрозумілий інтерфейс для:
- мешканців гуртожитку (студентів);
- адміністрації та комендантів;
- модераторів/персоналу.

Система замінює паперові журнали та ручний облік цифровими процесами.

---

## ⚙️ Технологічний стек

- **React 19** — побудова інтерфейсу
- **JavaScript (ES6+)**
- **SCSS** — стилізація
- **Redux Toolkit** — глобальний стан
- **React Router v6** — маршрутизація
- **Axios** — HTTP-запити до бекенду
- **Vite / CRA** — збірка проєкту *(залежно від конфігурації)*
